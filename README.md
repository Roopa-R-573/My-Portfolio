# Roopa R React Portfolio

This React project is recreated from the uploaded `port.html` design.

## Run

Open the project folder in VS Code terminal:

```bash
npm install
npm run dev
```

Open the local Vite URL, normally:

```text
http://localhost:5173
```

## Files

- `src/main.jsx` - React components and portfolio content
- `src/style.css` - complete responsive styling
- `index.html` - React entry page
- `package.json` - dependencies and scripts

## Customize

Change your email in `src/main.jsx`.

Update project links/images in the `projects` array.

The contact form currently shows a confirmation alert. It does not send an email by itself. Connect it to a backend/email service to receive real messages.

The original design used external video, images and icons, so this version keeps those external assets while converting the page structure into React components.
